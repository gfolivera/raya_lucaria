# Descrição
Projeto de website de cadastro e matrícula de cursos da Academia Raya Lucaria, do jogo Elden Ring da empresa FROM SOFTWARE.

# Tecnologias
## Front-end
Desenvolvido em React Typescript, com Vite e chamadas de API com AXIOS.

## Back-end
Desenvolvido em PHP, atendendo requisições de login, criação de cadastro, matrícula em cursos, com dados armazenados em um banco de dados MySQL, utilizando prepared statements.
